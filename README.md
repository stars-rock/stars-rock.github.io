# stars-rock.github.io

Одностраничный сайт-витрина услуг: автоматизация работы с документами и данными (сверка документов, поиск по архивам, регулярные отчёты на AI-агентах, RAG и локальных моделях).

**Сайт:** <https://stars-rock.github.io/>

Репозиторий — публикационная копия: здесь лежит готовый сайт, который отдаёт GitHub Pages. Правки лучше вносить в исходники, а не здесь: при очередной публикации файлы будут перезаписаны.

## Что внутри

```
index.html          главная страница, девять разделов
404.html            страница ошибки (GitHub Pages отдаёт её на любой несуществующий адрес)
styles/
  tokens.css        цвета, размеры, отступы, кривые анимации — единственный источник значений
  fonts.css         локальные @font-face
  main.css          сетка, секции, компоненты
scripts/main.js     появление блоков при прокрутке, вкладки FAQ, копирование почты
assets/
  fonts/            PT Serif и Onest, подмножества cyrillic и latin (woff2)
  icons/            favicon (svg, ico) и apple-touch-icon
  img/              превью ссылки (og.png) и фото в разделе «Контакт» (avif, webp, jpg)
.nojekyll           отключает сборку Jekyll: сайт отдаётся как есть
```

## Как устроен

- Чистая статика: HTML, CSS и немного JavaScript. Сборки и зависимостей нет.
- Никаких внешних запросов: шрифты, иконки и картинки локальные, без CDN, счётчиков и трекеров.
- Тёмная тема, один акцентный цвет. Размеры и отступы заданы в `rem`, корневой кегль растёт с шириной окна (16 px до 1440 px, 18 px на 1920 px), поэтому страница одинаково читается на ноутбуке и на большом мониторе.
- Доступность: семантическая разметка, ссылка «К содержимому», видимый фокус, контраст по WCAG 2.1 AA, `prefers-reduced-motion` отключает анимации. Автоматическая проверка axe-core: 0 нарушений.
- Адаптивность: проверено от 375 до 2167 px, без горизонтальной прокрутки.

## Посмотреть локально

Пути в разметке абсолютные (`/assets/...`), поэтому сайт нужно открывать с корня адреса, а не как файл:

```bash
python -m http.server 8000
```

Затем открыть <http://localhost:8000/>. Подойдёт и любой другой статический сервер, например `npx serve`.

## Публикация

GitHub Pages: ветка `main`, корень репозитория. Изменения появляются на сайте через 1–10 минут после отправки в `main`.

Если сайт переедет на другой адрес, замените `https://stars-rock.github.io` в трёх метатегах `index.html`: `canonical`, `og:url` и `og:image`. Для собственного домена добавьте файл `CNAME` с его именем.

## Шрифты

PT Serif и Onest распространяются по открытой лицензии SIL OFL; в `assets/fonts` лежат подмножества этих шрифтов.
